# Contributing

Thanks for your interest in WalletPrint.

## Development

```bash
npm install
npm test
npm run build
```

## What to contribute

Useful contributions include:

- SDK bug fixes and type improvements
- new examples for agent-wallet or account-abstraction integrations
- documentation improvements
- test coverage for edge cases in request mapping

## Scoring model changes

This repository contains the SDK client only. Changes to scoring rules, thresholds, or the hosted API belong in the private WalletPrint product repo and are not accepted here.

## Security

Do not commit secrets. `.env` files are ignored.

If you find a security issue, do not open a public issue with exploit details. Contact the maintainer privately first.
